# Ficha: contexto público y registro personal

2026-09-19 · v0.9.0 abierta. Modo Operate.

El owner eligió conservar el dossier y mejorar su composición. La obra y su registro
personal llevan el protagonismo; puntajes públicos y streaming aportan contexto.
Pidió indicadores compactos de biblioteca/plataforma: color cuando hay disponibilidad
y gris cuando no. Iconos propios de cassette y pantalla, acompañados por texto,
distinguen ausencia confirmada, consulta pendiente, información desconocida y error.
Alquiler/compra no se confunden con disponibilidad por suscripción, gratis o anuncios.

Se conserva portada, identidad, sinopsis, edición y ficha técnica existentes. Los datos
públicos se presentan después del registro, sin tarjetas anidadas: fuente, escala y
votos; luego país y ofertas agrupadas por forma de acceso. Atribuciones del servidor
visibles. El país se puede elegir sólo si la política de instancia lo habilita.
Las preferencias de plataformas ignoradas se conservan al cambiar de país.

Cada consulta falla y se reintenta independientemente; una respuesta tardía nunca
modifica otra ficha ni borra un formulario. Sólo se conectan obras del catálogo propio:
el ID de una obra de Club no autoriza consultar datos del catálogo personal.
La contratapa VHS conserva su presentación.

X8.4: el registro manda sólo campos modificados y su base original. Un conflicto
conserva la edición y muestra la versión actual. La persona elige conservar su edición
o usar la versión recibida; conservar exige volver a guardar con la base actualizada.
Un fallo de privacidad no repite un guardado personal ya realizado con una base vieja.

ausencia, pocos votos, elección de país, respuestas tardías y guardado concurrente.
